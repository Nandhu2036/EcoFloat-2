# Contributing to EcoFloat-2

We welcome community members and roboticists to help improve the EcoFloat-2 autonomous cleanup system.

## Code of Conduct
All contributors must abide by our [Code of Conduct](CODE_OF_CONDUCT.md).

## Re-Engineering Guidelines
If you are developing new hardware modules, custom CAD hulls, or software pathing logic:
1. Ensure all CAD designs are saved in neutral format (`.step`, `.stl`) alongside source parameters (`.f3d`).
2. Document physical properties, Metacentric calculations, and motor draws under `/docs`.
3. Submit testing logs showing local simulation correctness before filing a PR.
