# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-30
### Added
- Complete active waste collection catamaran project structure.
- Fully organized CAD models folder (`/models/cad`) containing step, stl, and f3d designs.
- Production-ready Python software stack under `/src` supporting Edge AI inferences (TFLite) and differential thruster steering.
- Local simulation script (`/src/simulation/sim_run.py`) to run and verify target locking and proportional control loops.
- Comprehensive engineering math, electronics, and software manuals under `/docs`.
