# Project Overview: EcoFloat 2.0

EcoFloat 2.0 represents the active-remediation upgrade of the EcoFloat project. It transitions from an observational sensor platform (v1.0) into a fully **automated water surface debris skimmer**.

## Upgrades in Version 2.0
1. **Passive Nozzle Flow**: Avoids motor-driven conveyor belts entirely by using hydrodynamic pressure to guide waste.
2. **Onboard Edge AI**: Processes frames locally via a quantized object detection model on the Raspberry Pi 4 CPU.
3. **Differential Propulsion**: Transom-mounted marine thrusters allow the catamaran to execute zero-turn maneuvers without mechanical rudders.
